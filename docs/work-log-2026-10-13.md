# 2026-10-13 작업 기록

## 1. 시각화 개편 (철거 비용 본문)
- 공통 본문 `app/components/CostCore.tsx`: 실적 카드 → 지원금("아직도 내 돈 들여 철거하시나요?") → 평당 비용 그래프 → 흐르는 사진 띠 → 상황 → 견적서 → 금액을 바꾸는 5가지 → 현장 사진 → 범위 → 견적 체크 → 3단계.
- 시각화 컴포넌트 `app/components/CostVisuals.tsx`, 스타일 `app/cost-visuals.css`(cv- 클래스).
- 적용: `/guide/철거-비용/`, 시군구 철거비용 271개. 시군구는 지역 고유 내용(지역 조건·지역 Q&A·지역 정보)을 모두 최하단에 모음.

## 2. 철거전문업체 개편
- 공통 본문 `app/components/CompanyCore.tsx`: 실적 → 지원금 → 업체에 물어볼 5가지(+지역 대표이미지) → 사진 띠 → 맡기면 달라지는 것·현장답사~마무리·업종 격자·현장 사진·범위 → 3단계. 평당 비용 그래프는 넣지 않음(검색 의도·카니발 방지).
- 적용: `/guide/철거전문업체/`, 시군구 철거전문업체 271개.

## 3. 하위 가이드 6개
- 폐업·사무실·식당·상가·원상복구·폐업지원금: 실적 카드 상단, 지원금 섹션(지원금 가이드 제외), 비용 표 → 그래프, 사진 띠, 체크리스트·카드 시각화.

## 4. 사실 점검
- 비용 구성: 보양·양중비 → 안전관리비(스페이스로그인·소중함인사이트 공통 항목). 금액 요인: 작업 시간 → 건물 구조·자재.
- "금액이 올라가는 경우"에서 근거 없는 야간·주말 할증, 후드·덕트 등 제거.
- FAQ "집기 매입은 하지 않습니다"(폐업·사무실·식당) → 철거와 함께 매입 가능(10/7 사용자 확인 사실)으로 수정.
- 지원금 최대 600만원(2025.7.11 이후 폐업, 그 전 400만원)은 언론·공고 요약으로 교차 확인. 공고 HWP 원문은 직접 열람 못 함.
- 미확인 채로 둔 것(사용자 확인 불가로 패스): 공용부 보양·방진막, 관리사무소 협의 대행, 폐기물 신고 대행 등 작업 설명. "이미 철거를 마쳤어도 신청 가능" FAQ와 "철거 전 신청 필수" 정리글 간 충돌.

## 5. 유사도
- 문구 변형 `app/lib/cost-copy.ts`, `app/lib/company-copy.ts`(C_DIFF·C_SCOPE 등 추가), 가운데 섹션 순서 변형.
- 배정값 재계산: `node --max-old-space-size=12288 scripts/tune-region-salts.mjs 20 3`, `scripts/tune-company-salts.mjs 20 3`(먼저 `npm run build`).
- 결과(글자 단위 difflib, 본문): 철거비용 지역끼리 평균 47.8%(같은 시도 49.5%), 철거전문업체 49.0%(49.8%). 최고값 65~75%는 지역 정보가 적은 지역끼리.
