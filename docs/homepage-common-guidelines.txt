# 상품 변경형 홈페이지 제작 공통 지침

작성일: 2026-08-03

이 문서는 배움길에서 다른 상품 홈페이지를 만들 때 매번 같은 설명을 반복하지 않기 위한 고정 지침입니다.  
새 상품 페이지를 만들기 전에는 이 문서를 먼저 확인하고, 상품별로 달라지는 내용만 교체합니다.

## 1. 기본 원칙

1. 기존 배움길 공통 UI는 유지합니다.
2. 상품이 바뀌어도 Header, Navigation, Footer, 우측 하단 플로팅 상담 버튼, 하단 혜택 CTA는 임의로 수정하지 않습니다.
3. 새 상품 페이지는 기존 확정 페이지의 섹션 흐름과 디자인 톤을 재사용합니다.
4. 바꿔야 하는 것은 상품명, 타겟, 문제 상황, 해결 방식, 증거자료, SEO 제목, 메타설명, H1, 본문 문장입니다.
5. 타사 브랜드명, 타사 로고, 상표, 실사 인물 이미지는 그대로 사용하지 않습니다.
6. 레퍼런스 이미지를 받을 경우 이미지 안의 텍스트는 읽어 반영하되, 브랜드명과 저작권 요소는 배움길 기준으로 대체합니다.
7. 과장, 보장, 근거 없는 1등 표현, 허위 후기, 허위 성과는 사용하지 않습니다.
8. 학부모가 이해하기 쉬운 단어와 상담 전환에 도움이 되는 설명을 우선합니다.
9. 검색엔진용 보조 정보는 사용자 설득 본문보다 아래에 배치합니다.
10. 작업 완료 후에는 SEO 제목, 메타설명, OG 설정, 깨진 링크/이미지, 모바일 화면을 함께 확인합니다.

## 2. 새 상품 제작 전에 반드시 받을 정보

새 상품 홈페이지를 만들 때는 아래 정보만 있으면 제작을 시작할 수 있습니다.

- 상품명
- 상품을 부르는 화면 표기명
- 노출시키고 싶은 대표 키워드
- 주요 타겟
- 타겟이 겪는 문제
- 상담 신청 시 고객이 얻는 이익
- 상품의 핵심 해결 방식
- 수업/서비스 진행 방식
- 가격 또는 혜택 공개 여부
- 사용 가능한 후기, 사례, 이미지, 영상, 문서 자료
- 금지해야 할 단어 또는 브랜드명
- 만들 페이지 범위

정보가 부족하면 임의로 성과나 사실을 만들지 않고, 확인 가능한 범위에서만 구성합니다.

## 3. 상품 페이지 기본 섹션 흐름

상품별 특성에 따라 일부 섹션은 생략할 수 있지만, 기본 흐름은 아래 순서를 우선합니다.

1. Hero
   - H1은 1개만 사용합니다.
   - 상품명보다 고객의 문제와 변화가 먼저 보이게 구성합니다.
   - 첫 화면에서 “누구에게 필요한 상품인지” 바로 이해되어야 합니다.

2. 가치 입증 또는 핵심 수치
   - 실제 운영 데이터, 서비스 범위, 수업 방식, 관리 방식 등 확인 가능한 정보만 사용합니다.
   - 숫자가 없으면 억지 수치를 만들지 않습니다.

3. 문제 공감 섹션
   - 고객이 현재 겪는 어려움을 구체적으로 설명합니다.
   - “왜 지금 상담이 필요한지” 자연스럽게 이어지게 만듭니다.

4. 해결 방식 섹션
   - 상품이 문제를 어떻게 해결하는지 단계별로 설명합니다.
   - 단순 기능 나열보다 고객에게 생기는 변화와 이익을 중심으로 씁니다.

5. 적용 대상 섹션
   - 어떤 학생, 학부모, 상황에 효과적인지 구체적으로 작성합니다.
   - 맞지 않는 대상이 있으면 과장하지 않고 상담에서 확인한다고 표현합니다.

6. 진행 과정 섹션
   - 상담부터 시작, 진단, 선생님 연결, 수업/관리, 피드백까지 흐름을 보여줍니다.
   - 고객이 다음 행동을 예측할 수 있어야 합니다.

7. 사례/후기/증거 섹션
   - 제공된 자료만 사용합니다.
   - 개인정보는 이름 가운데 글자를 `*`로 처리합니다.
   - 실사 얼굴은 그대로 사용하지 않고 일러스트 또는 비식별 이미지로 대체합니다.

8. FAQ
   - 고객이 상담 전에 가장 많이 물어볼 질문을 넣습니다.
   - 카드 크기와 여백은 간결하게 유지합니다.

9. 참고 정보/내부링크
   - SEO 확장을 위한 보조 정보는 FAQ 아래에 배치합니다.
   - 본문과 직접 관련 없는 정보는 안내 문구로 구분합니다.

10. 공통 Footer
   - 확정된 배움길 Footer를 사용합니다.

## 4. 본문 작성 기준

1. 학부모 친화적인 문장으로 씁니다.
2. 어려운 마케팅 용어보다 “무엇을 확인하고, 어떻게 도와주는지”를 먼저 말합니다.
3. 고객이 얻는 이익을 명확하게 씁니다.
4. 단순히 서비스 기능을 나열하지 않고, 변화 결과를 함께 설명합니다.
5. 본문 텍스트는 너무 작게 만들지 않습니다.
6. 중요한 단어는 색상 강조 정도로만 사용하고, 과한 밑줄이나 장식은 피합니다.
7. 공통 UI 텍스트 크기와 카드 스타일은 임의로 바꾸지 않습니다.
8. 문단마다 같은 말이 반복되면 줄이고, 각 섹션의 역할을 분리합니다.

## 5. 상담 전환 문구 기준

상담 CTA는 “지금 신청하세요”보다 상담을 통해 얻는 이익을 먼저 보여줍니다.

권장 방향:

- 지금 수업 진행 시, 상담 혜택 제공
- 첫 상담에서 아이의 현재 상태와 필요한 수업 범위를 먼저 확인
- 학년, 과목, 막히는 단원을 남기면 수업 가능 여부를 안내
- 무리한 약속보다 아이에게 필요한 방향을 먼저 안내

금지 방향:

- 성적 향상 보장
- 무조건 합격
- 누구나 1등
- 상담만 하면 바로 해결
- 근거 없는 무료/환불/혜택 표현

## 6. SEO 기본 기준

1. 페이지마다 `title`, `meta description`, H1은 고유하게 작성합니다.
2. H1은 페이지당 1개만 사용합니다.
3. SEO 제목은 대표 키워드를 포함하되 키워드를 반복하지 않습니다.
4. 메타설명은 80~150자 안에서 상품, 대상, 문제, 상담 이익을 요약합니다.
5. 같은 문장을 여러 페이지에 반복하지 않습니다.
6. URL은 짧고 이해하기 쉽게 구성합니다.
7. 내부링크는 표준 `<a href="">` 링크로 제공합니다.
8. `noindex`, `nofollow`는 특별한 이유 없이 사용하지 않습니다.
9. 대표 URL은 canonical로 자기 자신을 가리키게 합니다.
10. OG title, OG description, OG image를 설정합니다.

## 7. 대량 페이지 생성 기준

지역, 학교, 과목, 상품 조합으로 대량 페이지를 만들 때는 아래 기준을 따릅니다.

1. 기준 페이지를 먼저 1개 만들고 사용자가 확인한 뒤 대량 생성합니다.
2. 기준 페이지의 섹션 흐름, CSS, Header, Footer, 플로팅 버튼은 유지합니다.
3. 페이지별로 바꿀 항목은 SEO 제목, 메타설명, H1, 본문 첫 문단, 지역/학교/상품 문장, 내부링크입니다.
4. 유사도 기준은 본문 설득 영역 기준 80% 미만을 목표로 합니다.
5. 유사도를 낮추기 위해 억지 문장이나 부자연스러운 지역 설명을 넣지 않습니다.
6. 공개 데이터, 학교 데이터, 지역명, 하위 지역, 내부링크를 활용하되 고객이 읽어도 자연스럽게 씁니다.
7. 검색엔진용 보조 정보는 FAQ 아래에 둡니다.
8. 작업 완료 후 SEO 제목, 메타설명, OG 설정, 유사도 결과 예시를 보고합니다.

## 8. 이미지 제작 및 적용 기준

1. 새 이미지는 가능하면 WebP로 저장합니다.
2. 이미지 파일은 `brand-assets/images` 또는 상품별 폴더에 정리합니다.
3. 레퍼런스 이미지를 그대로 복사하지 않습니다.
4. 사람 얼굴이 포함된 경우 실사 원본을 그대로 쓰지 않고 일러스트, 비식별 이미지, 새 생성 이미지로 대체합니다.
5. 선생님 프로필 이미지는 대표 이미지나 OG 이미지로 사용하지 않습니다.
6. 본문 이미지는 문장 가까이에 배치하고 alt 텍스트를 자연스럽게 작성합니다.
7. 이미지가 깨지면 즉시 대체 이미지를 적용합니다.

## 9. 레퍼런스 이미지 처리 기준

사용자가 레퍼런스 이미지를 주면 아래 방식으로 처리합니다.

1. 이미지 안의 텍스트를 읽습니다.
2. 사용할 수 있는 문구는 최대한 유지합니다.
3. 타사 브랜드명은 배움길 또는 해당 상품명으로 바꿉니다.
4. 타사 로고, 상표, 실사 인물, 저작권 이미지 요소는 그대로 쓰지 않습니다.
5. 필요한 이미지는 새로 생성하거나 비식별 이미지로 대체합니다.
6. 레이아웃은 참고하되, 배움길 공통 디자인과 충돌하지 않게 조정합니다.
7. 구현 후 사용자가 수정할 수 있도록 먼저 테스트 페이지로 보여줍니다.

## 10. 네이버/구글 검색 기준

네이버 서치어드바이저와 구글 SEO 기준을 반영해 아래 항목을 유지합니다.

- `robots.txt`에서 검색로봇 접근을 막지 않습니다.
- 사이트맵은 절대 URL로 생성합니다.
- 네이버/구글 소유확인 메타를 유지합니다.
- CSS, JS, 이미지 등 핵심 리소스를 차단하지 않습니다.
- 모든 주요 페이지는 HTML 안에서 콘텐츠를 읽을 수 있어야 합니다.
- 깨진 링크와 깨진 이미지를 업로드 전 점검합니다.
- 모바일에서 메뉴, CTA, 플로팅 버튼이 겹치지 않는지 확인합니다.
- 중복 URL은 canonical 또는 301 리디렉션으로 정리합니다.

## 11. 금지어 및 표현 기준

아래 표현은 기본적으로 사용하지 않습니다.

- 타사 브랜드명
- `코치`
- `타겟7조`
- `운용 1조`
- 내부 운영팀 이름
- 고객에게 불필요한 관리용 표현
- 성적 보장 표현
- 합격 보장 표현
- 근거 없는 1위/최고/유일 표현
- 개인정보가 드러나는 실명

선생님 관련 표현은 `선생님`으로 통일합니다.

## 12. 업로드 전 체크리스트

새 상품 페이지 또는 대량 페이지를 배포하기 전 아래 항목을 확인합니다.

- H1이 페이지당 1개인가?
- title과 meta description이 있는가?
- OG title, description, image가 있는가?
- canonical이 올바른가?
- noindex, nofollow가 들어가지 않았는가?
- 깨진 내부링크가 없는가?
- 깨진 이미지가 없는가?
- sitemap.xml에 새 페이지가 포함되었는가?
- robots.txt가 검색로봇을 허용하는가?
- Header, Footer, 플로팅 버튼이 기존과 동일한가?
- 모바일 화면에서 메뉴와 CTA가 겹치지 않는가?
- 타사 브랜드명과 금지어가 남아 있지 않은가?
- 개인정보가 비식별 처리되었는가?

## 13. 작업 완료 보고 형식

상품 페이지 제작 또는 대량 생성 작업이 끝나면 아래 항목을 함께 보고합니다.

1. 생성/수정한 페이지
2. 적용한 SEO 제목 예시
3. 메타설명 예시
4. OG 이미지 설정
5. 깨진 링크/이미지 점검 결과
6. 모바일 화면 확인 결과
7. 수정하지 않은 공통 요소 확인

## 14. 새 상품 요청 시 기본 프롬프트

사용자가 새 상품 홈페이지를 요청하면 아래 기준으로 이해합니다.

> 기존 배움길 공통 디자인, Header, Footer, 플로팅 버튼, CTA, 색상, 카드, 타이포그래피는 유지한다.  
> 상품명, 타겟, 문제 상황, 해결 방식, 증거자료, SEO 제목, 메타설명, H1, 본문만 새 상품에 맞게 바꾼다.  
> 레퍼런스 이미지는 텍스트와 흐름을 참고하되, 타사 브랜드와 저작권 요소는 사용하지 않는다.  
> 작업 전 기준 페이지를 만들고, 확인 후 대량 생성한다.
