# Cheolgeoon AI Image Pool

This folder is for AI-generated photorealistic concept images used as optional
section-support assets for the Cheolgeoon demolition website.

These images are not real demolition case photos and must not be presented as
completed work examples, customer proof, before/after evidence, or testimonials.
